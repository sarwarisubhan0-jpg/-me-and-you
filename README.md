# Me & You
Static page (`index.html`) + one Vercel function (`api/analyze.js`).

1. Get a free key at https://aistudio.google.com/apikey
2. Push this folder to GitHub, import it in Vercel.
3. Add env var `GEMINI_API_KEY` (optional: `GEMINI_MODEL`, default `gemini-2.5-flash`). Deploy.
4. Open the Vercel URL on your iPhone and test with a real chart screenshot.

Not tested against the live API yet. Free-tier limits and model names can change; check Google AI Studio.
